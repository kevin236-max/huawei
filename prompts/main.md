- 每个候选是能够在新进程独立执行的 Python 文件，必要辅助函数写在同一文件中，顶层定义依赖、参数列表和以下接口：

```python

def fit(train_data, num_months, candidates):
    return state

```

- 顶层 `candidates` 是准备比较的整批方案。`fit` 的 `candidates` 是本次实际执行的方案；验证传入整批，最终测试只传入 `[选中的参数]`。
- 每项参数完整描述可独立执行的方案，包括可调特征、模型参数、成员组合、融合权重和随机种子。使用 JSON 支持的类型，浮点数必须有限。固定代码配置无需重复记录，验证确定的轮数、权重和校准系数应保存在代码或参数中。
- `train_data` 和 `history_data` 是 pandas.DataFrame，第一列 `month` 为 `YYYY-MM` 字符串，其余列为站点径流 float64，与训练 CSV 列顺序一致；按月递增、连续、无缺失，径流有限且为正。
- `train_data` 是允许用于拟合的数据；`num_months` 是预测月份数；`state` 保存模型、统计量、共享特征和参数，供随后各次预测复用。
- `history_data` 包含截至本次起报月的完整真实观测，末行是起报月；`target_months` 是其后连续 `num_months` 个月的 `list[str]`。起报月推进后，历史中加入新发生的真实观测。
- `predict` 返回 numpy.ndarray 组成的列表，与传给 `fit` 的参数顺序一一对应。每个数组形状为 `[len(target_months), 站点数]`，按目标月份和 CSV 站点顺序排列；预测必须是原始径流尺度的有限非负值。只有一个方案时也返回长度为 1 的列表。
- 整批与单参数执行必须遵循相同训练和预测规则，不能依赖参数在整批中的位置或其他方案的存在。

### 实验设计

- 分数为 `score = 1 - mean_station(mean_records(abs(prediction - truth) / truth))`，越高越好。各站先汇总全部预测记录，再等权平均；同一目标月份在不同起报和提前期下分别计分。
- 转换目标或使用其他训练损失时，预测仍需还原到原始径流尺度。融合先组合预测再评分，成员分数的加权平均不代表融合分数。
- 根据任务特点和已有结果提出方案，探索不同的模型结构、特征表示或预测方式。
- 每个任务说明一个值得验证的想法，以及它可能改善当前结果的原因。具体方案写到 subagent 可以直接实现的程度，包括输入、目标、模型结构和主要参数。
- 调参策略给出主要参数、初始比较范围，以及根据结果继续调整或结束的条件。围绕同一想法安排少量有辨识力的比较，将其他方法或较大改动留给后续任务。
- 改进已有方案时，先简要说明背景，再说明参考文件、需要保留的部分和本次修改内容。融合任务说明成员参数、预测尺度及权重搜索策略。
- 验证安排说明需要完成的内部检查和正式评估，根据返回结果安排下一轮的方法改进和参数搜索。
- subagent 未获得分数时，结合已完成代码和失败原因，决定续接实现、修复或调整方案。

### 共享计算与训练要求

- 同一候选中，各方案通过 `fit` 和 `predict` 共享数据处理、成员训练和基础预测；只改变融合权重、缩放或截断时复用成员预测。最终单参数重训只准备选中方案需要的成员。
- 模型和预处理统计量只能使用传入的 `train_data` 拟合。训练样本的输入和目标都在该训练段内，样本起报不早于任务给出的首个允许起报月；训练与预测使用同一特征定义。
- `predict` 使用固定训练结果和方案参数，按当前历史构造输入。需要早停时，先在内部历史留出上选轮，再将确定轮数纳入方案；留出预处理仅在对应拟合段确定，校准残差须来自未拟合对应目标的模型。
- 每个随机成员明确设置种子，使整批与单独执行一致。需要比较多个种子时，在实验指令中安排，并记录集成的种子和组合方式。
- 正式执行仅携带候选代码和参数，不能依赖临时模型、缓存、参考文件或 `analysis`。
